# ece-cooked

> Two-player co-op cooking game in C with Allegro 4, built as a first-year project at ECE Paris.

## Features
- Main menu (play / rules / quit) with keyboard navigation and background music
- Player name input for both players
- Two players on the same keyboard with animated sprites
- Wall collisions read from a colour collision map (`carte2.bmp`) drawn under the kitchen (`carte1.bmp`)
- Game timer

## Build
CMake (CLion) + **Allegro 4.4**. Put the files from `assets/` next to the executable.
